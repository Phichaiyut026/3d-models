# Astral Warden

เกมแอ็กชัน 3D มุมมองบุคคลที่สาม สร้างด้วย Godot 4.7, GDScript และ C++ (GDExtension)

## เล่นเกม

```bash
godot --path .
```

เกมเริ่มที่เมนูหลัก มีหน้าวิธีเล่นและหน้าตั้งค่า (ความไวเมาส์ ความละเอียด คุณภาพกราฟิก เต็มจอ) ค่าที่ตั้งจะถูกบันทึกไว้

## เลือกตัวละคร

กด **เริ่มเกม** แล้วเลือกว่าจะเล่นตัวไหน เลื่อนเมาส์ผ่านการ์ดจะเห็นตัวละครนั้นยืนอยู่ในฉากด้านหลังเมนู

| ตัวละคร | รายละเอียด |
| --- | --- |
| GEMINI | นักดาบแห่งดวงดาว ปลดล็อกร่างใหม่ตามเนื้อเรื่อง (ร่างแรก, ร่างสูงสุด, ร่าง ARGON) |
| อั้ม · ABYSS | ร่างแห่งความมืดจาก `aum.html` ดำสนิททั้งตัว ตาขาวเรืองแสง อยู่ในร่างนี้ตลอดและแปลงร่างไม่ได้ ไม่มีใครสู้ได้ |

สกิลของอั้ม (ปุ่ม 1 - 8): หลุมดำ, หนามมืด, ลำแสงทำลาย, กองทัพเงา, อุกกาบาตมืด, ประตูนรก, โซ่ว่างเปล่า, จุดจบของทุกสิ่ง

## โครงสร้าง

- `native/src/` C++: สร้างภูมิประเทศ, กระจายหญ้าและพร็อพ, สร้างภาพเนบิวลา
- `scripts/` GDScript: ตัวละคร การต่อสู้ ศัตรู HUD และการสร้างโลก
- `shaders/` เชดเดอร์ทั้งหมด

## คอมไพล์ส่วน C++ ใหม่

ต้องมี `scons` และโฟลเดอร์ `native/godot-cpp`

```bash
cd native && scons target=template_debug arch=arm64 api_version=4.7
```

ถ้าจะ export เกมเป็นไฟล์ติดตั้ง ให้คอมไพล์เพิ่มด้วย `target=template_release`

## ทดสอบอัตโนมัติ

```bash
godot --path . -- --autotest --shots=/tmp/shots
```

ทดสอบอั้ม: หน้าเลือกตัวละคร การไม่เปลี่ยนร่าง และสกิลทั้ง 8

```bash
godot --path . -- --autotest --abyss --shots=/tmp/shots
```
