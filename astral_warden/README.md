# Astral Warden

เกมแอ็กชัน 3D มุมมองบุคคลที่สาม สร้างด้วย Godot 4.7, GDScript และ C++ (GDExtension)

## เล่นเกม

```bash
godot --path .
```

เกมเริ่มที่เมนูหลัก มีหน้าวิธีเล่นและหน้าตั้งค่า (ความไวเมาส์ ความละเอียด คุณภาพกราฟิก เต็มจอ) ค่าที่ตั้งจะถูกบันทึกไว้

## การควบคุม

| ปุ่ม | การกระทำ |
| --- | --- |
| WASD / เมาส์ | เดิน / หมุนกล้อง |
| Shift | วิ่ง |
| Space | กลิ้งหลบ (ไม่โดนโจมตีระหว่างกลิ้ง) |
| คลิกซ้าย / C | ฟันต่อเนื่อง 3 จังหวะ / ฟันหนัก |
| คลิกขวา | ป้องกัน |
| F | ยิงดาว (ใช้พลังสีฟ้า) |
| R | ดื่มน้ำอมฤต (ฟื้นพลังชีวิต 50%) |
| X | เสกดาบ / เก็บดาบ (กดฟันตอนไม่ถือดาบก็เสกให้เอง และเก็บเองเมื่อเลิกสู้ 5 วินาที) |
| Q | ล็อกเป้า |
| E / U | พักที่แท่นดาว / เสริมพลังด้วยละอองดาว |
| Esc | หยุดเกม |

## โครงสร้าง

- `native/src/` C++: สร้างภูมิประเทศ, กระจายหญ้าและพร็อพ, สร้างภาพเนบิวลา
- `scripts/` GDScript: ตัวละคร การต่อสู้ ศัตรู HUD และการสร้างโลก
- `shaders/` เชดเดอร์ทั้งหมด

## คอมไพล์ส่วน C++ ใหม่

ต้องมี `scons` และโฟลเดอร์ `native/godot-cpp`

```bash
cd native && scons target=template_debug arch=arm64 api_version=4.7
```

ถ้าจะ export เกมเป็นไฟล์ติดตั้ง ให้คอมไพล์เพิ่มด้วย `target=template_release`

## ทดสอบอัตโนมัติ

```bash
godot --path . -- --autotest --shots=/tmp/shots
```
